# s-dock

Док-бар для Hyprland — спутник [ashell-ru](https://github.com/JS-2006/ashell-ru).
Тот же стек: Rust + iced (layer-shell), TOML-конфиг с hot-reload.

> Только Hyprland (включая новые версии с Lua-конфигом; старые hyprlang тоже
> поддержаны через автоматическое определение диалекта IPC).

## Возможности

- Режимы: **fixed** (резервирует место под окнами) и **popup**
  (скрытая полоска-хотспот у края экрана → наведение → док выезжает,
  автоскрытие по таймауту `autohide_timeout`, по умолчанию 3 с).
- Позиция: низ/верх/лево/право × выравнивание центр/край; ширина
  `fit` (по контенту + радиус) или `full` (весь экран + вынос за края
  на радиус).
- Иконки приложений из `.desktop` с многоступенчатым фолбэком
  (тема → без темы → pixmaps); точки под иконками = количество окон.
- ЛКМ: запуск / фокус; несколько окон → попап со списком окон
  (клик по строке = фокус нужного окна).
- ПКМ: контекстное меню — закрепить/открепить, открыть, закрыть,
  список окон.
- Drag-and-drop: перетаскивание пинов (live-перестановка), вытягивание
  приложения за пределы дока запускает новый экземпляр.
- Hover-эффект: иконка увеличивается на `hover_scale` с выходом за край дока.
- Кнопка лаунчера: позиция start/end, эмодзи/текст, команда.
- На каждый монитор; hot-reload конфига и pins.toml.

## Сборка и запуск

```bash
make check   # fmt + clippy -D warnings
make build   # cargo build --release
make start   # собрать и запустить
```

Зависимости: те же, что у ashell-ru (libxkbcommon, libwayland, dbus, pipewire не нужен).

## Конфиг

`~/.config/s-dock/config.toml` — полный пример: [docs/config-example.toml](docs/config-example.toml).
Пины: `~/.config/s-dock/pins.toml` — пример: [docs/pins-example.toml](docs/pins-example.toml).
Оба файла перечитываются на лету при изменении.

Логи: `/tmp/s-dock/s-dock.log` (`RUST_LOG=debug` для отладки IPC).
