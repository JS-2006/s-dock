# s-dock — SPEC (утверждена, v1)

> Этот файл — замороженная спецификация. Менять только по явной просьбе владельца.
> Статус реализации см. в docs/PLAN.md.

## Что это

s-dock — док-бар для Hyprland, проект-спутник ashell-ru (`~/projects/ashell-ru`).
Пишется «в духе» ashell-ru: Rust + iced_layershell fork, Elm-архитектура
(`App` → `Message` → `update`/`view`), TOML-конфиг с hot-reload через inotify.

## Ключевые решения владельца (зафиксированы в диалоге 2026-08-26)

1. **Композитор: только Hyprland.** IPC-слой переносится из ashell-ru:
   `src/services/compositor/hyprland_ipc.rs` (probe `/eval return 1` → режим
   Lua/Legacy; Lua-диспетчи `hl.dsp.*`; legacy fallback для старых версий).
2. **Пины** хранятся в отдельном файле состояния `~/.config/s-dock/pins.toml`
   (НЕ в основном конфиге).
3. **Лаунчер**: команда задаётся в конфиге (`launcher.cmd`, напр. `"fuzzel"`).
4. **Док на всех выходах** (поверхность на каждый output, паттерн Outputs ashell-ru).
5. **Всплывающий режим**: пока док скрыт, у края экрана лежит тонкая прозрачная
   полоска-хотспот; курсор на ней → док появляется; курсор покинул док → док
   прячется, полоска возвращается.
6. **Размеры полоски-хотспота** задаются в конфиге: ширина (`"dock"` = как у дока,
   или число px) и высота (px).
7. **Точка запущенного приложения** под иконкой: вкл/выкл, цвет, размер из конфига.
8. **Ширина дока**: `"fit"` (по числу приложений) или `"full"` (весь экран) — из конфига.
9. **Слои**: `popup` = `Overlay` + exclusive_zone −1 (поверх всех окон, ничего
   не сдвигает); `fixed` = `Top` + exclusive_zone = dock_size (резервирует
   место под окнами, не перекрывая их).
10. **Кнопка лаунчера**: позиция в ряду (`position = start|end`, относительно
    кластера приложений; кластер центрируется) и цвет текста (`text_color`)
    задаются в конфиге.
11. **Прозрачность элементов через конфиг**: `appearance.opacity` (подложка и
    рамка дока), `launcher.opacity` (надпись кнопки); для новых элементов —
    по аналогии отдельное поле `opacity`.
14. **Иконки**: если `Icon=` не найден в теме — фолбэк-цепочка: абсолютный
    путь из .desktop → поиск по лестнице размеров (тема → без темы) →
    каталоги `*/share/pixmaps` (png/svg). Промахи НЕ кэшируются.
15. **Несколько окон приложения**: под иконкой N точек (по числу окон);
    ЛКМ открывает попап со списком окон (иконка+заголовок, клик = фокус),
    повторный ЛКМ по иконке или уход курсора закрывает попап. Настоящие
    пиксельные миниатюры (ext-image-copy-capture) — отдельная задача.
16. **ЛКМ на незапущенное приложение** запускает его; на одно окно — фокус.
13. **Пины**: файл `~/.config/s-dock/pins.toml` (рядом с конфигом), формат
    `pins = ["firefox.desktop", ...]` — порядок в файле = порядок в доке.
    Пины показываются всегда (даже когда приложение не запущено); запущенные
    окна приложения «прилипают» к его пину. Внешние правки файла подхватываются
    на лету. Открепление/перетаскивание появится с контекстным меню (этап 6)
    и drag-and-drop (этап 4).
12. **Автоскрытие в popup-режиме**: если курсор не на доке
    `popup.autohide_timeout` секунд (по умолчанию 3; 0 = отключить) — док
    прячется. Показ: наведение на прозрачную полоску-хотспот у края экрана.
    Пока dock скрыт, его input region пуст (не ловит клики), полоска активна;
    когда показан — наоборот.

## Функциональные требования

- Режимы: `fixed` (резервирует место через exclusive_zone) / `popup` (см. выше).
- Размещение из конфига: позиция `bottom|top|left|right` × выравнивание
  `center|start|end`.
- Закрепление приложений на доке; перемещение пинов drag-and-drop внутри дока.
- Вытягивание иконки с дока на рабочий стол → запуск нового экземпляра приложения.
- Фокус-эффект: иконка под курсором увеличивается на 30% (`hover_scale`),
  выходит за пределы подложки дока (поверхность заранее больше видимого ряда).
- Контекстное меню по ПКМ на иконке: закрепить/открепить, открыть, закрыть,
  список открытых окон приложения (клик по окну → фокус этого окна).
- Кнопка вызова лаунчера: вкл/выкл + эмодзи/надпись из конфига.
- Оформление настраивается через конфиг (цвета, скругления, отступы, размер иконок).

## Конфиг (эскиз, утверждён)

```toml
position = "bottom"      # bottom|top|left|right
alignment = "center"     # center|start|end
mode = "popup"           # fixed|popup

[appearance]
icon_size = 40
dock_size = 64           # толщина подложки дока (высота/ширина по ориентации)
width = "fit"            # "fit" | "full"
margin = 6
spacing = 8
background_color = "#1e1e2ecc"
border_radius = 18
border_color = "#89b4fa00"
hover_scale = 1.3
show_running_indicator = true
running_indicator_color = "#89b4fa"
running_indicator_size = 5

[popup]
hotspot_width = "dock"   # "dock" | число px
hotspot_height = 8

[launcher]
enabled = true
label = "🚀"             # эмодзи или текст
cmd = ""                 # путь к лаунчеру
```

Имена полей при реализации могут уточняться, семантика — нет.

## Поведение кликов

- ЛКМ по иконке: не запущено → запуск; запущено → фокус (одно окно); несколько
  окон → фокус последнего активного (или меню окон — уточнить на этапе 6).
- ПКМ → контекстное меню (см. выше).

## Технические факты (проверено исследованием, не перевыпроверять)

- Сокеты Hyprland не менялись: `$XDG_RUNTIME_DIR/hypr/$HIS/.socket.sock`
  (запросы `[flags]/request`), `.socket2.sock` (события `EVENT>>DATA\n`).
- Чтение состояния: `j/workspaces`, `j/clients`, `j/activewindow` и т.п. работают
  во всех версиях. События: `openwindow`, `closewindow`, `activewindow(v2)`,
  `focusedmon(v2)`, `submap`.
- Диспетчи ≥0.55 (Lua): фокус окна `hl.dsp.focus({window = "0xADDR"})`,
  закрытие `hl.dsp.window.close("0xADDR")`. Legacy: `dispatch focuswindow address:...`,
  `dispatch closewindow address:...`.
- Ответы сокета: успех начинается с `ok`; ошибки `error:` / `unknown request`.
